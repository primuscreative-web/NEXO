# Phase 1 API contracts

The canonical executable contract is generated by NestJS at `/openapi` and all Phase 1 routes are under `/v1`.

## Identity

- `POST /auth/register`, `/auth/verify-email`, `/auth/login`, `/auth/logout`, `/auth/refresh`
- `POST /auth/forgot-password`, `/auth/reset-password`, `/auth/change-password`
- `GET /auth/me`, `/auth/sessions`
- `DELETE /auth/sessions/:id`; `POST /auth/sessions/revoke-others`

## Tenant administration

- organization list, create, read, update and active selection;
- membership list, status/role update and revocation;
- invitation create, accept, resend and revoke;
- team list, create, read, update/archive, add member and remove member;
- role, permission and authorized audit-log queries.

Errors use `{ error: { code, message, correlationId } }`. Tenant mismatch is intentionally surfaced as `404`; authenticated denial is `403`; malformed input is `400/422`. Membership, team, session and audit collections use bounded cursor pages shaped as `{ items, nextCursor }`; organization and role catalogs remain bounded by product invariants. Request schemas reject undeclared properties through the global validation pipe.

Mutation requests authenticated by cookies require `X-CSRF-Token`. The web API client reads the CSRF cookie and never persists bearer or refresh tokens in browser storage.
